## What's changed

- **Fixes v0.1.39, which never started.** v0.1.39 was the first version built on GitHub, and that build picked up a different SDL2 library that needs a file the download didn't include. It showed "Failed loading SDL3 library", went back to v0.1.38 by itself, and tried again at the next start. This version is built with the same SDL2 as before, and the build now stops if that library ever changes again. If you saw those errors, this version installs by itself and they stop.

Everything new in v0.1.39 comes with this version:

- **Fewer sound dropouts when a stream starts.** Across real sessions, the PS5 sent sound in bursts for the first few seconds, and half of the first dropouts came in the first 3 seconds. For the first 8 seconds, the app now waits for a bigger backlog of sound, up to 150 ms. After that, it catches up on its own: it skips a 10 ms bit of near silence now and then until the sound is back to its usual delay. In a simulation built from those sessions, dropouts in the first 8 seconds went from about 5 to under 2 per stream, and dropouts afterwards stayed about the same.
- **A maximized video window goes full screen.** With the taskbar and title bar taking room, a maximized window is never 16:9, so the picture had bars at the sides. Maximizing now fills the screen, like `F11`. Press `F11` or `Esc` to go back to the window, at the same size and place as before.
- **The log says where gamepad presses go.** The first press in each session is logged as sent to the PS5, or as not sent with the reason. The connection report counts presses. This is for finding out why a gamepad doesn't work for some people.
- **The download includes third-party licenses.** `THIRD-PARTY-NOTICES.txt` lists every library in the app with its version, license and full license text, and says where to get the source code.
- **Releases are built on GitHub.** Versions are now built by GitHub Actions from the code in the repository, not on someone's PC.

Connecting wasn't changed.

## How to update

On v0.1.22 or later, you don't need to do anything. The app installs this version by itself, either right after it opens or once audio and video are both off. On older versions, reopen the app and press **Update** at the bottom.

Or download `PS-Stream-v0.1.40-windows-x64.zip`, extract it, and open `PS Stream.exe`. Keep the folder together. Windows may warn you because the app isn't signed: choose **More info**, then **Run anyway**. Your pairing and settings carry over.

## Known issues

- With the same PSN account you play on, the DualSense stops working on the PS5 while the app is connected. Pair the app with a second PSN account to keep using it.
- Turning video on or off during a session reconnects. The PS5 takes about 8 seconds to accept the new connection.
- Some people report that a gamepad on the PC doesn't control the PS5. If that happens to you, note the time and share your `log.txt`.
